What it guarantees

  • Delayed jobs only. Every email becomes a BullMQ delayed job keyed by its UUID; nothing polls a clock.
  • Limits are enforced in one atomic Redis Lua call — per-sender hourly counter, optional global counter, and minimum spacing between sends, shared by every worker instance.
  • Over-limit jobs are delayed, never dropped. The worker calls moveToDelayed and raises DelayedError.
  • Restart-safe. Startup recovery re-enqueues Postgres rows that have no live job, so killing API and worker mid-flight loses nothing.
  • Idempotent. An Idempotency-Key replay returns the original campaign instead of duplicating it.
  • Honest states. Loading skeletons, empty states with a next action, and retryable error panels on every page.
